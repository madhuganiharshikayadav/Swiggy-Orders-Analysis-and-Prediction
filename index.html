Prediction Problem

The target variable is derived from DeliveryTimeMinutes. Any order with delivery time > 45 minutes is labelled as a Late Delivery. This creates a binary classification problem solved entirely client-side with logistic regression via gradient descent — no backend required.

Features

  • One-hot encoded Zone, Cuisine, PaymentMethod
  • Binary IsFirstOrder
  • Standardized continuous: DistanceKM, PrepTimeMinutes, OrderValueINR

Why Logistic Regression?

It is fast to train in the browser, produces well-calibrated probabilities, and the coefficients remain directly interpretable — important when explaining “why this order is high-risk” to operations teams.

Limitations

  • The model retrains on every page load / Excel upload using an 80/20 seeded split, so metrics can shift slightly.
  • It is a linear model over a modest feature set. A production system would use cross-validation, richer features (traffic, weather, partner load) and a gradient-boosted model trained offline.
  • Synthetic seed data is provided so the demo works immediately. Upload your real Swiggy export for accurate results.
